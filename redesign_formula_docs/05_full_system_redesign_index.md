## 总体改造主线

```text
矿石块段/可磨性/矿物组成
  -> 入口边界三路线与二溢过程样
  -> 磁选组分回收与混磁精矿
  -> 塔磨解离和三次分级粒度
  -> 浮选一粗一精三扫组分平衡
  -> 最终精矿品位与过程化验样
```

## 输出分层

### DCS 变量

DCS 变量仍作为软测量训练主特征。它们必须来自传感器、设备状态、操作量和物理过程，不能由目标品位反推。

### 隐藏状态

隐藏状态用于模块之间传递真实因果量，例如：

```text
Fe_mag, Fe_hem, Fe_carb, Fe_sil
F200, F325, f25
Liberation
Concentration
Matrix_clog
Circulating_load
```

默认不输出到训练特征。

### 过程化验变量

过程化验变量使用 `lab_*` 命名。它们不设置化验滞后，可按采样时刻直接写入，用于：

- 日常指标跟踪。
- 流程考查样。
- 数据质量校验。
- 多任务学习标签。
- 分析 DCS 软测量模型是否真的学到过程路径。

## 后续实现建议

建议按以下顺序改代码：

1. 先增加隐藏组分状态和 `lab_*` 输出管线，不改变现有 DCS 列名。
2. 改入口边界发生器，生成三线二溢等价边界样；不模拟破碎和球磨内部。
3. 替换磁选段为组分质量平衡模型。
4. 替换塔磨/三次分级粒度模型。
5. 替换浮选段为段级组分模型，并移除泡沫高度对 `TFe_circuit` 的反推。
6. 最后做全流程校准和泄漏检查。
